# 위시켓 지원서 — ReframeBot (규칙 기반 질문-응답-답장 자동화 플랫폼 MVP)

---

## 클라이언트의 질문

### Q1. 이 프로젝트를 성공적으로 수행할 수 있는 제안이 있으십니까? (500자)

우선 정확한 요구사항을 함께 확인하는 과정이 필요합니다. 현재 공개된 정보를 바탕으로 규칙 기반 질문-응답-답장 자동화 플랫폼을 자의적으로 해석하여 구현해둔 상태입니다. 따라서 구체적인 규칙 정의(매칭 조건, 템플릿 구조, 검수 기준)만 명확히 해주시면 빠르게 맞춤 조정이 가능합니다.

데이터 파이프라인 측면에서는 MVP 단계에서 데이터 양이 대규모로 발생하지 않을 것으로 보여, BigQuery 같은 별도 분석 인프라 없이 Supabase(PostgreSQL)만으로 충분합니다.

다만 개인적인 제안으로, 규칙 관리는 조건이 늘어날수록 유지보수가 어려워집니다. 초기에는 값싼 AI 모델 API를 연동하여 기본 응답을 생성하고, 축적된 질문-응답 데이터를 바탕으로 AI Agent를 구축하면 운영 부담을 줄이면서도 답변 품질을 점진적으로 높일 수 있습니다.

---

### Q2. 프로젝트와 관련된 솔루션 활용 경험이 있다면 설명해주세요. (500자)

Firebase Remote Config는 앱 업데이트 없이 서버에서 조건(사용자 세그먼트, 앱 버전, 지역 등)에 따라 설정값을 다르게 내려주는 룰 기반 원격 제어 도구입니다. 사내에서 이 도구의 도입이 불가하여, 동일한 구조의 규칙 엔진을 직접 설계·구현했습니다. 숫자·문자·앱 버전 등 다양한 타입에 대해 AND, OR, <=, >= 등 연산자를 조합하는 조건 매칭을 지원합니다.

이 과정에서 가장 중요했던 점은 디버깅 가시성이었습니다. 하나의 대상에 적용되는 규칙이 많아질수록 최종 결과 예측이 어려워지기 때문에, 규칙 적용 전 결과를 미리 확인할 수 있는 프리뷰 화면과, 어떤 규칙에 의해 왜 이 결과가 나왔는지 추적할 수 있는 디버깅 로그를 함께 구축했습니다.

이 경험은 본 프로젝트의 규칙 매칭 엔진 설계, 관리자 검수 큐, 그리고 매칭 결과 추적(어떤 규칙이 왜 적용됐는지) 기능 구현에 직접적으로 활용됩니다.

---

### Q3. 프로젝트와 관련된 사업 분야 업무 경험에 대해 설명해주세요. (500자)

위 Q2에서 언급한 룰 기반 시스템은 5M+ 사용자 규모의 자체 서비스에서 A/B 테스트 및 런타임 기능 분기 처리(Feature Flag) 용도로 실제 운영한 경험입니다.

구체적으로는, 앱 버전·사용자 세그먼트·시간대 등 복합 조건에 따라 기능 노출 여부를 실시간으로 제어하는 시스템을 설계하고, 배포 없이 운영자가 직접 규칙을 변경할 수 있도록 관리 화면을 함께 구축했습니다.

이 경험은 본 프로젝트에서 요구하는 "규칙 정의 → 조건 매칭 → 결과 분기"의 전체 흐름과 구조적으로 동일합니다. 규칙 우선순위 충돌 관리, 조건 조합의 복잡도 제어, 운영자 친화적인 CMS 설계 등 실제 서비스 운영에서 겪은 문제와 해결 경험을 그대로 적용할 수 있습니다.

## 지원 내용

<프로젝트 진행 제안>

먼저 요구사항 확인 미팅을 통해 규칙 정의와 운영 시나리오를 구체화한 후 작업에 착수합니다. 이미 자체적으로 해석하여 구현해둔 MVP가 있어, 규칙만 확정되면 빠르게 맞춤 조정 가능합니다.

• 1단계: 요구사항 확인 — 규칙 정의, 매칭 조건, 템플릿 구조, 검수 기준 합의
• 2단계: 규칙 엔진 조정 + DB 스키마 확정 + 인증 셋업
• 3단계: 사용자 UI(메시지함, 응답 폼, 히스토리) + 관리자 CMS(규칙/템플릿/기수 CRUD, 검수 큐)
• 4단계: 크론잡(질문 발송/만료), 데이터 내보내기, 배포 + 시연

매일 작업 완료 시점에 진행 상황을 공유드리며, Vercel Preview 배포로 실시간 확인 가능합니다. 향후 AI 연동 확장 시의 아키텍처도 미리 고려하여 설계합니다.

<유사 프로젝트 진행 경험>

• 룰 기반 Feature Flag 시스템: 5M+ 사용자 서비스에서 Firebase Remote Config 대체 시스템 자체 구축. 숫자/문자/앱버전 타입별 AND/OR/<=/>=  연산자 조합, 규칙 프리뷰 + 디버깅 로그 구현.
• n8n 고객 문의 자동화: 웹 폼 → n8n 웹훅 → AI 분류 → Slack 알림 → Google Sheets 로깅 → 자동 응답 전체 파이프라인 구축.
• 관리자 CMS: Supabase + Next.js App Router 기반 뉴스/포트폴리오/채용/문의 관리 어드민 패널 구현.
• Google Sheets 재고 대시보드: Server Actions + optimistic UI + 실시간 데이터 동기화 구현.

<사용 기술과 툴>

• 프레임워크: Next.js (App Router), TypeScript, Tailwind CSS
• UI: shadcn/ui, React Hook Form + Zod, Zustand
• DB/인증: PostgreSQL + Prisma, NextAuth.js (매직링크)
• 규칙 엔진: TypeScript 커스텀 매칭 엔진 (조건 조합 + 우선순위 기반)
• 배포: Vercel
• 커뮤니케이션: 위시켓 메시지 + 필요 시 Slack/Discord
