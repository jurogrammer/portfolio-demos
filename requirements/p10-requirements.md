## 1. 문서 목적

본 문서는 ScholarSync KR MVP의 제품 요구사항을 정의한다. 한국 대학생·대학원생·학부모를 대상으로 파편화된 장학금 정보를 통합 검색하고, 기관별 자기소개서 초안을 AI로 즉시 생성해주는 서비스의 범위·기능·성공 지표를 명시하여, 후속 기술 설계서와 개발 일정의 기준선이 되도록 한다.

---

## 2. 배경 및 문제 정의

### 2.1 시장 배경

- 한국의 등록금·생활비 부담은 매년 가중되고 있으며, 사립대 평균 등록금은 연 750만 원을 상회한다.
- 한국장학재단 외에도 100여 개의 사설 재단(아산, 관정이종환, 일주학술문화 등)과 광역·기초 지자체가 다양한 장학금·청년 지원금을 운영한다.
- 그러나 정보가 각 기관 웹사이트에 흩어져 있고, 자격 요건과 제출 양식이 표준화되어 있지 않다.

### 2.2 사용자 Pain Point

1. **정보 탐색 비용**: 자신에게 맞는 장학금을 찾기 위해 수십 개 사이트를 일일이 방문해야 한다.
2. **자격 요건 해석의 어려움**: "차상위", "기초생활수급", "학업 우수성 + 리더십" 등 모호한 기준을 본인에게 적용하기 어렵다.
3. **자기소개서 작성 부담**: 기관마다 항목·글자수·톤이 달라 매번 처음부터 써야 하며, 글쓰기에 대한 두려움으로 지원 자체를 포기하는 사례가 많다.
4. **마감일 관리 실패**: 분산된 일정 때문에 자격이 충분함에도 마감을 놓친다.

## 3. 타겟 사용자

|---|---|---|

## 4. 제품 비전 및 목표

### 4.1 비전
> "학생이 등록금 걱정 대신 공부에 집중할 수 있도록, 장학금 탐색과 지원을 10분 안에 끝낸다."

### 4.2 MVP 목표 (출시 후 8주)
- 누적 가입자 **1,000명**
- 자소서 생성 후 **원본 사이트 이동 클릭률 50%**
- 7일 재방문율 **30%**
- NPS **40 이상** (인앱 서베이, 최소 응답 50건 이상 확보 시 유효)

## 5. 핵심 가치 제안

1. **통합 검색**: 한국장학재단 + 사설 재단 + 지자체 장학금을 한 화면에서.
2. **개인화 매칭**: 프로필 기반(학교·학점·소득분위·지역·전공) 조건 필터링으로 자격 요건 자동 매칭.
3. **즉시 자소서 초안**: 기관별 항목에 맞춰 5~15초 내 한국어 초안 생성.
4. **마감일 알림**: 매칭된 장학금의 마감일을 이메일로 알림.

## 6. MVP 기능 요구사항

### 6.1 P0-A: 핵심 루프 (W1~W2, 2주 스프린트)

MVP 첫 스프린트에서 반드시 작동해야 하는 최소 기능 세트.

| ID | 기능 | 설명 | 수용 기준 |
|---|---|---|---|
| F-01 | 회원가입/로그인 | 이메일·카카오 OAuth (Supabase Auth) | 가입 후 30초 내 온보딩 진입 |
| F-02 | 프로필 입력 | 학교, 학과, 학년, 학점, 소득분위, 지역, 관심분야 | 5분 내 작성 가능, 이후 수정 가능 |
| F-04 | 장학금 매칭 | 조건 기반 필터링 (소득분위·학점·지역·전공·학위과정) | 매칭 결과 2초 이내, 상위 10건 표시 |
| F-05 | 장학금 상세 보기 | 자격, 금액, 마감일, 자소서 항목, 원본 링크 | 모든 정보 1화면 제공 |
| F-06 | 자소서 초안 생성 | 기관별 항목·글자수에 맞춘 한국어 초안 | 첫 글자 출력 3초 이내, 스트리밍, AI 생성물 고지 표시 |
| F-07 | 자소서 편집/저장 | 사용자가 수정 후 저장, 복사, 다운로드 | 자동 저장(5초 디바운스), 복사 시 클립보드 반영 확인 |

```
[랜딩] → [회원가입] → [프로필 입력] → [성적표 업로드 (선택)]
```

- **자소서 완성 → 원본 사이트 이동** 클릭을 핵심 전환 이벤트로 추적.

### 8.2 데이터 수집 전략

- **1차 소싱 (W1~W2)**: 수동 큐레이션 100건 — 한국장학재단(국가장학금·푸른등대), 주요 사설 재단 20곳, 서울·경기 지자체.
- **2차 소싱 (W3~W5)**: 200건 추가 — 공공데이터포털 API 활용 가능 항목 자동화, 나머지 수동.
- **갱신 정책**: 신규 데이터 추가는 주 1회. 기존 데이터는 `deadline` 기준으로 자동 `is_active=false` 처리 (cron job).

## 9. 자소서 생성 기능 상세

### 9.1 입력값

| 소스 | 데이터 |
|---|---|
| 프로필 (자동) | 학교, 학과, 학년, 학점, 소득분위, 지역 |
| 장학금 (자동) | 기관명, 장학금명, essay_prompts (항목별 질문·글자수) |
| 사용자 입력 (선택) | 자기소개 키워드, 주요 경험·활동, 지원 동기 핵심 문장 |

### 9.2 출력 요구사항

- 각 essay_prompt 항목별로 `max_chars` 이내의 한국어 초안 생성.
- 스트리밍 출력 (SSE), 첫 글자 3초 이내.
- 출력 상단에 **"이 글은 AI가 생성한 초안입니다. 반드시 본인의 경험과 생각으로 수정한 후 제출하세요."** 고지 표시 (AI 기본법 준수).
- 글자수 충족률 90% 이상 (max_chars의 80~100% 범위).

### 9.3 LLM 설정

- **모델**: OpenAI API (GPT-4o — 자소서 생성 + Vision PDF 파싱 겸용)
- **비용 추정 기준**: 자소서 1건 평균 입력 1,000토큰 + 출력 2,500토큰
- **캐싱**: 동일 장학금+유사 프로필 조합에 대해 시스템 프롬프트 캐싱 적용 (비용 절감)
- **Rate Limit**: 무료 사용자 1회/일, 유료 사용자 플랜별 제한

### 9.4 표절 방지 가이드라인

- 생성된 초안 상단에 가시적 AI 생성물 고지 텍스트 삽입.
- 복사 시 고지 텍스트 포함 여부는 사용자 선택.
- 이용약관에 "AI 초안을 그대로 제출하여 발생하는 문제에 대해 서비스는 책임지지 않음" 명시.
- 동일 장학금에 대해 매번 다른 초안이 생성되도록 temperature 설정.

## 12. 수익 모델

### 12.1 MVP 시점 (W1~W8): 무료 운영

MVP 기간에는 **결제 기능을 구현하지 않는다**. 사용자 획득과 제품 검증에 집중.

| 플랜 | 가격 | 포함 내용 |
|---|---|---|
| 무료 | 0원 | 매칭 검색 무제한, 자소서 생성 **3회/월** |

### 12.2 Post-MVP 결제 도입 시: 2-tier

| 플랜 | 가격 | 포함 내용 |
|---|---|---|
| 무료 | 0원 | 매칭 검색 무제한, 자소서 생성 **1회** |
| 베이직 | 4,900원 (단건) | 자소서 **5회**, 구매 후 **30일** 유효 |

가격 근거: 한국 대학생 구독 지불 저항선(5,000원 이하) 내 진입. 매칭 검색은 무제한으로 풀어 사용자 유입 극대화, 자소서 생성에서 결제 전환 유도.

### 12.3 장기 목표: 3-tier (P1 기능 완성 후)

| 플랜 | 가격 | 추가 내용 |
|---|---|---|
| 프리미엄 | 9,900원/월 | 자소서 무제한, 첨삭 피드백, 우선순위 매칭 |

| **ScholarSync KR** | ✅ 통합 (재단+지자체) | ✅ 프로필 기반 | ✅ AI 초안 | **차별점: 검색→생성 원스톱** |
