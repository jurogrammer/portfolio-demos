## 전체 인상
격식 있고 권위적인 정부 공식 사이트. 짙은 남색(navy) 배경 위에 백색 텍스트를 배치하여 신뢰감과 국가적 위엄을 표현한다. 대형 사진 중심의 히어로 캐러셀이 인상적이며, "임시 홈페이지"라는 안내 배너가 상단에 노출되어 과도기적 성격을 보여준다.

## 레이아웃 구조
- 전체 구성: 안내 배너 → 고정 헤더(nav) → 히어로 캐러셀(연설/뉴스) → 일정(국민과 함께하는 오늘) + 배너 카드 → 청와대 브리핑(카드 슬라이더) → 대통령의 순간들(사진/영상 그리드) → 푸터
- 컨테이너 최대 너비: 1200px (뷰포트 전폭)
- 섹션 간 간격: 섹션 간 별도 padding/margin 없이 배경색 전환으로 구분
- 그리드 시스템: Flexbox 기반 (Swiper 슬라이더 내 flex 레이아웃)
- 총 페이지 높이: 약 3553px
- 헤더: 고정(fixed), 높이 100px

## 컴포넌트 패턴

### Navigation
- 유형: 고정(fixed) 상단 헤더, 높이 100px
- 로고: 좌측 배치 (국장 이미지 + "대한민국 청와대" 텍스트)
- 메뉴: 우측 5개 항목 (대통령, 청와대, 미디어, 뉴스룸, 정보공개)
- 글자크기 변경 아이콘 제공 (접근성)
- 배경: 짙은 남색, 스크롤 시 transition 효과 (top 0.3s)

### Hero 섹션
- Swiper 캐러셀, 12슬라이드
- 좌우 2분할 레이아웃: 좌측 대형 사진(600px) + 우측 텍스트 영역(600px)
- 텍스트 영역: H2 제목(68px, bold) + 본문 발췌 + "자세히보기" CTA 링크
- 슬라이드 컨트롤: 이전/정지/다음 버튼 + 번호 페이지네이션 (01/10)
- 높이: 약 775px

### 일정 (국민과 함께하는 오늘)
- Swiper 슬라이더, 수평 카드형
- 각 카드: 날짜 + 일정 텍스트
- "더보기" 링크 제공
- 우측에 대통령 취임선서/국민주권예산 배너 카드 2개 배치

### 청와대 브리핑
- 수평 스크롤 카드 리스트 (6개)
- 각 카드: 제목(2줄) + 본문 발췌(여러 줄) + 날짜
- 이전/다음 슬라이드 버튼
- 배경: 짙은 남색(#00205C)

### 대통령의 순간들
- "사진으로 만나는 대통령" / "영상으로 만나는 대통령" 탭 전환
- 비정형 그리드 레이아웃: 대형 카드 1개 + 중형/소형 카드 혼합
- 각 카드: 사진 배경 + 제목 + 본문 발췌 + 날짜
- 영상 카드: 썸네일 + 재생 아이콘 오버레이

### Footer
- 높이: 121px
- 단순 구성: 주소(서울특별시 종로구 청와대로 1) + 저작권
- "맨 위로 올라가기" 버튼
- 배경: 짙은 회색(#333333)

## 인터랙션 & 애니메이션
- **Swiper 캐러셀**: 메인 히어로, 일정, 브리핑 모두 Swiper.js 사용
- **Transition 효과**: 대부분 0.2-0.3s ease (헤더, 버튼, 탭, 페이지네이션)
- **스크롤 애니메이션**: 클래스 기반 애니메이션 감지됨 (`[class*="animate"]`)
- **패럴랙스**: 없음
- **스무스 스크롤**: 미적용 (기본 브라우저 스크롤)
- **jQuery**: 사용 중 (DOM 조작, Swiper 제어)
- **Keyframe 애니메이션**: `swiper-preloader-spin` (로딩 스피너)

## 반응형 전략

- 글자크기 변경 접근성 도구 제공

## 특이사항 & 디자인 언어
- **임시 홈페이지**: "이재명 정부 청와대의 임시 홈페이지입니다. 새로운 디지털 소통 플랫폼을 현재 준비 중입니다." 배너 상시 노출
- **국장(國章) 로고**: 청와대 공식 문장 사용, 이미지 기반
- **다크 테마 전면 적용**: 전체 사이트가 짙은 남색 계열로 통일, 밝은 배경은 일정 섹션 등 제한적 사용
- **Swiper 의존도 높음**: 히어로, 일정, 브리핑 등 거의 모든 콘텐츠 영역이 캐러셀
- **클래스 네이밍**: 한국식 약어 혼합 (`ftSize`, `gnbFirst`, `slideBtnwrap`), BEM이나 Tailwind 미사용

## 브랜드 톤 & 카피
- 전체 톤: **authoritative** (권위적, 격식체)
- 시점: **we** (정부 시점) + **you** (국민 호칭, "국민 여러분")
- 헤드라인 패턴:
  - 구조: bold-statement (단정적 선언문)
  - 길이: 중간~긴 문장 (15-30자)
  - 예시: "대한민국 하늘을 넘어 세계의 하늘까지", "위기에 강한, 국민이 믿는 자본시장", "우리는 위기를 기회로 만들 충분한 역량이 있습니다"
- CTA 스타일:
  - 텍스트: "자세히보기", "더보기"
  - 톤: neutral/inviting (강요하지 않는 톤)
  - 시각적: text-link (밑줄 또는 화살표)
- 카피 밀도: **copy-heavy** (연설문 발췌, 브리핑 전문 등 텍스트 밀도 높음)
- 소셜 프루프: 없음 (정부 공식 사이트 특성상 불필요)
- 핵심 키워드: [국민, 대통령, 위기, 기회, 안보, 자주국방, 함께, 정부, 대한민국, 브리핑]
