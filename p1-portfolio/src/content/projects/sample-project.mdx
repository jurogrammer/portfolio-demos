## 프로젝트 개요

일 100K+ 트랜잭션을 처리하는 B2B SaaS 플랫폼을 설계하고 구현했습니다.

## 기술적 도전

### 성능 최적화

Redis 캐싱 전략과 데이터베이스 쿼리 최적화로 응답 시간을 70% 개선했습니다.

```java
@Cacheable(value = "userProfile", key = "#userId")
public UserProfileDto getUserProfile(Long userId) {
    return userRepository.findById(userId)
        .map(UserProfileDto::from)
        .orElseThrow(() -> new UserNotFoundException(userId));
}
```

### 시스템 아키텍처

| 서비스 | 역할 | 기술 |
|--------|------|------|
| Auth Service | 인증/인가 | Spring Security, JWT |
| User Service | 사용자 관리 | Spring Boot, PostgreSQL |
| Notification | 알림 처리 | Kafka, Redis |
